# qrcardmaker (QR名刺メーカー)

vCard形式のQRコードを生成するための、シンプルなクライアントサイドWebアプリケーションです。連絡先情報を入力して、デジタル名刺用のQRコードを作成できます。

## デモ

**ライブアプリケーション:** [https://code4fukui.github.io/qrcardmaker/](https://code4fukui.github.io/qrcardmaker/)

## 機能

*   ユーザーの入力からvCard 3.0形式のQRコードを生成します。
*   名前、フリガナ、所属、メールアドレス、URL、住所、電話番号の入力フィールドを備えています。
*   ブラウザ上で完全に動作し、サーバーへのデータ送信は行いません。
*   Vanilla HTML、CSS、JavaScriptで構築された、シンプルでレスポンシブなインターフェースです。
*   ビルドプロセスが不要な単一ファイルのアプリケーションです。

## 使い方

1.  [デモページ](https://code4fukui.github.io/qrcardmaker/)を開きます。
2.  用意されたフィールドに連絡先情報を入力します。
3.  **"QR生成"** (Generate QR) ボタンをクリックします。
4.  ボタンの下にQRコードが表示されます。
5.  スマートフォンのカメラでQRコードをスキャンし、連絡先情報をインポートします。
